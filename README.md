# Finance Tracker

A Python-powered cashflow tracker that connects to Google Sheets, previews your ledger data, and sets the stage for charting + calendar integration.

---

## 🚀 Current Status

- ✅ `tracker_api.py` authenticates with Google APIs
- ✅ Reads your **Ledger** tab from Google Sheets
- ✅ Displays a clean preview of your first rows in the terminal
- ✅ Project is safely committed (secrets ignored with `.gitignore`)
